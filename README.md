## 📦 Сборка для публикации

> [!WARNING]
> Обычный `next build` **не подходит** — сайт публикуется на shared-хостинге
> без Node.js, нужен статический экспорт.

```bash
# macOS / Linux
NEXT_OUTPUT_EXPORT=1 bunx next build

# Windows (PowerShell)
$env:NEXT_OUTPUT_EXPORT="1"; bunx next build
```

Результат — папка **`out/`**. На хостинг загружается её **содержимое** (не сама папка).

## 🛠 Деплой на хостинг

**Хостинг:** Reg.ru (ISPmanager) · домен stories-sochi.ru

**Вариант 1 — через панель:**
1. Собрать проект (см. выше)
2. Reg.ru → Хостинг → ISPmanager → Файловый менеджер
3. Открыть `/www/stories-sochi.ru/`, удалить старое содержимое
4. Загрузить содержимое `out/`

**Вариант 2 — скриптом по FTP** (быстрее, ~40 файлов за минуту):

```powershell
Get-ChildItem -Recurse -File out | ForEach-Object {
  $rel = $_.FullName.Substring((Resolve-Path out).Path.Length + 1).Replace('\','/')
  curl.exe -s -S --ftp-create-dirs -T $_.FullName "ftp://user:password@hosting-server/www/stories-sochi.ru/$rel"
}
```

> [!NOTE]
> - Логин, пароль и адрес FTP-сервера — в личном кабинете хостинга
>   (Reg.ru → карточка хостинга → вкладка **«Доступы»**)
> - Перед массовой загрузкой старую версию удобно переносить в бэкап-папку на сервере
> - `.htaccess` уже внутри `out/` — HTML отдаётся с `no-cache`, hashed-ассеты с годичным кэшем
> - Если изменения не видны — **Ctrl+F5**

## 🧾 Как править меню

Всё меню живёт в **`src/lib/menu-data.ts`**. Иерархия:

```
MENU (категории = вкладки)
 └── pages (подразделы = переключатели внутри вкладки)
      └── groups (заголовки секций)
           └── items (позиции: name, description, price, hit)
```

**Добавить блюдо:**

```ts
{
  name: "Паста Карбонара",
  description: "330 гр · паста фетучини, бекон, яйцо, пармезан, сливки",
  price: "550",
  hit: true,          // опционально: бейдж «Хит»
}
```

**Добавить подраздел во вкладку** — новая запись в `pages` категории:

```ts
pages: [
  { label: "Блины и закуски", groups: [/* ... */] },
  { label: "Новый подраздел", groups: [{ title: "Секция", items: [/* ... */] }] },
]
```

После правки — собрать и задеплоить (см. выше).

## 📌 Зафиксированные решения по контенту

> Менять только по явной просьбе владельца

- Заголовок раздела — **«Завтраки»** (без «весь день»), но в `note` указано «весь день»
- В hero — «Рейтинг 5.0»; в контактах — «5 из 5 — оценок «отлично»»
- Адрес одной строкой: **«г. Сочи, ул. Виноградная, 2/3Б»**, без индекса и региона
- Часы работы — **до 21:00**
- Карточки «Заходите и проверяйте» — статичные, без анимаций
- Кнопка «Мы на Яндекс Еде» удалена; из внешних ссылок только Яндекс Карты
- Заголовки, надпись STORIES, рейтинг и изображения защищены от копирования
