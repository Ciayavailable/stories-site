# PROJECT.md — контекст проекта (для человека и ИИ-агента)

## Что это
Одностраничный сайт кафе «Stories» (г. Сочи, ул. Виноградная, 2/3) — stories-sochi.ru.
Стек: Next.js (App Router) + TypeScript + Tailwind CSS + framer-motion.
Сайт публикуется как СТАТИКА на обычном хостинге (без Node.js на сервере).

## Запуск и сборка

```bash
bun install        # один раз после распаковки
bun run dev        # локальная проверка → http://localhost:3000
```

СБОРКА ДЛЯ ПУБЛИКАЦИИ (важно: обычный `next build` не подходит!):

```bash
# macOS / Linux:
NEXT_OUTPUT_EXPORT=1 bunx next build

# Windows (PowerShell):
$env:NEXT_OUTPUT_EXPORT="1"; bunx next build
```

- Результат — папка `out/`. На хостинг загружать СОДЕРЖИМОЕ `out/` (не саму папку).
- `next.config.ts` сам переключает режим экспорта по переменной `NEXT_OUTPUT_EXPORT`.
- НЕ создавать API routes (`src/app/api/**`) — они ломают статический экспорт.

## Где что лежит
- `src/lib/menu-data.ts` — ВСЁ МЕНЮ И ЦЕНЫ. Типы: `MenuCategory` (может содержать
  `pages: MenuPage[]` — постраничные вкладки), `MenuGroup`, `MenuItem`
  (name, price, description?, hit?).
- `src/components/site/` — секции страницы:
  - `hero.tsx` — первый экран (STORIES, бейдж «Рейтинг 5.0»)
  - `about.tsx` — блок о кафе
  - `features.tsx` — плитки «Заходите и проверяйте» (БЕЗ анимаций — так решил владелец)
  - `menu-section.tsx` — меню с переключателем страниц внутри категорий
  - `contacts.tsx` — телефон, адрес, кнопка «Открыть в Яндекс Картах»
  - `header.tsx`, `footer.tsx` — шапка и подвал
- `src/app/layout.tsx` — SEO: title / description
- `src/app/globals.css` — стили + запрет копирования: h1/h2/h3 (`user-select: none`),
  изображения (`user-select`, `-webkit-user-drag`, `pointer-events: none`)
- `public/images/` — hero.png, barista.png

## Публикация на хостинг
1. Собрать проект (см. выше) → появится папка `out/`
2. Личный кабинет reg.ru → Хостинг → ISPmanager → Файловый менеджер
3. Открыть `/www/stories-sochi.ru/` — удалить старое содержимое (саму папку оставить)
4. Загрузить содержимое `out/`
5. Проверить сайт (если изменения не видны — Ctrl+F5)

## Инфраструктура
- Домен: stories-sochi.ru (регистратор Reg.ru), NS NS_SERVERS → IP SERVER_IP
- Хостинг: Reg.ru, панель ISPmanager, корень сайта `/www/stories-sochi.ru/`
- SSL: Let's Encrypt (сертификат le1), продлевается автоматически;
  лишний самоподписанный le2 в панели можно удалить
- Оплата: хостинг оплачен до ДД.ММ.ГГГГ, баланс аккаунта 0 ₽ — пополнить заранее,
  иначе сайт перестанет открываться
